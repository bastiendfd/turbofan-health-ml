# Data Policy

This repository intentionally contains **no external turbofan dataset**.

## Included

- Small synthetic data generated at runtime for tests and demonstrations.
- A parser for the common 26-column C-MAPSS-style text layout.

## Not included

- NASA C-MAPSS raw files.
- Kaggle/Hugging Face mirrors.
- Real engine, maintenance, supplier, employer or customer data.
- Trained model artifacts.

## Optional local use

Place a source-verified, lawfully obtained C-MAPSS-style text file under `data/raw/` (ignored by Git). Review the upstream terms and document the exact source/revision in your local experiment notes.

Do not treat this portfolio baseline as a validated maintenance or safety model.
