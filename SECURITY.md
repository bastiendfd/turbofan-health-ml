# Security Policy

## Scope

Turbofan Health ML is a local educational experiment using synthetic test data. It is not a production or safety-critical model.

## Never add

- employer, customer, supplier or confidential maintenance data;
- credentials, API keys, tokens, private keys or proprietary documents;
- raw external datasets without verified provenance and terms;
- trained model artifacts from untrusted sources.

## Current limitations

The project has no authentication, access controls, model registry, provenance tracking, model monitoring or safety-case process. It must not inform operational, engineering, safety or maintenance decisions.

## Reporting

Do not disclose vulnerabilities or sensitive data through public issues. Use private GitHub security reporting once configured.
